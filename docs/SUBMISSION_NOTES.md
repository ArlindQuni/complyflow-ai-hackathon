# Submission notes

## Positioning

Turn incoming regulatory change into evidence-backed execution.

## Demo path

1. Organisation Profile — show configured EU scope, monitored topics and team routing.
2. Compliance Inbox — show working-now ingestion channels and seeded DORA item.
3. New Analysis — show public URL/file/paste intake and extracted-content review after URL import.
4. DORA analysis — show real public Commission Delegated Regulation (EU) 2025/301 hero.
5. Evidence grounding — select an obligation and inspect the matching source excerpt.
6. Human review — summaries, risk, suggested owners and plans remain drafts.
7. Execution — checklist/status and audit-style timeline.
8. Review & Handoff — JSON/CSV exports.
9. How It Works — prototype boundaries and Cloud/Private production roadmap.

## Claim boundaries

- Every extracted obligation that survives grounding is backed by a verbatim source excerpt.
- Unsupported calendar dates are removed.
- Summaries, risk scores, owner suggestions and plans are drafts for human review.
- Current prototype uses browser-local workspace state and has no auth/shared database.
- Live enterprise connectors are not claimed.
- Cloud/Private enterprise deployment is roadmap.
